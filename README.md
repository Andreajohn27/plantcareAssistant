# Plant Care Assistant

A Java-based terminal application for managing plant information and keeping track of basic plant care requirements.

### Features
- Add and view plants
- Search plants by name
- Update plant details
- Delete plants
- Generate care reminders
- Clear all plant data

### Technologies
Java

### Concepts Used
- Classes and objects
- Arrays
- Constructors
- Loops and conditional statements
- User input using `Scanner`

### How It Works
The application stores plant details such as plant name, type, watering frequency, fertilizer frequency, and sunlight requirements.
